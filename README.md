## Cloudflare Workers 自动部署

仓库根目录的 `wrangler.jsonc` 定义静态资源部署。Cloudflare Builds 使用 `main` 分支、Root directory `/`、Build command 留空、Deploy command `npx wrangler deploy`。Wrangler 会自动运行 `node scripts/prepare-cloudflare.mjs`，将网站文件复制到 `dist/`；不上传 ZIP、Git 元数据或本地备份文件。根路径 `/` 是编辑版，`/play`（或 `/play.html`）是游玩版，`/assets/` 保留视频资源。

推送后在 Cloudflare 的 Builds 中确认对应提交部署成功；推送成功本身不代表部署成功。

## 自定义手机

已内置用户提供的七张图标：相册、相机、小红书、微博、微信、Safari、备忘录。原图嵌入页面脚本，通过界面裁切去掉外围背景，无需额外上传图片目录。桌面和 Dock 使用同一套图标；自行上传过的图标优先保留，点“还原”可恢复这套默认图标。

- **设置 → 壁纸与锁屏密码**：分别上传锁屏和主屏幕壁纸。选图后显示与当前手机同比例的预览，支持鼠标／手指拖动、缩放和左右／上下位置滑杆。
- **壁纸完整显示 / 铺满屏幕**：新图片默认“完整显示”，保持原图比例、不裁切，多余区域使用深色填充。“铺满屏幕”保持比例并裁切超出部分，可拖动保留人物。放大后仍可能裁切。点“保存”应用，点“取消”保留原壁纸。
- **调整已有壁纸**：点锁屏或主屏幕预览直接修改构图，不必重新上传。两张壁纸独立保存构图，刷新、切换屏幕尺寸和 JSON 备份恢复后继续使用各自的适配设置；旧备份保持原来的居中铺满方式。支持独立重置。
- **设置密码**：输入两次相同的 4 位或 6 位数字。更改和关闭密码需填写当前密码。
- **锁屏**：设置 → 立即锁定；点“向上轻扫以解锁”或实际向上滑动。设置密码后显示数字键盘，电脑也能使用数字键和退格键。连续输错五次会等待 30 秒。
- **设置 → 应用图标**：可分别为相册、相机、小红书、微博、微信、Safari 和备忘录上传图片。支持缩放以裁去外围背景；桌面与 Dock 同步更新。图标保存在浏览器和 JSON 完整备份中；换设备需导入备份。
- **照片**：上传相片后，在照片页面底部选择桌面小组件使用的图片。未指定时显示相册第一张照片。
- **天气小组件 → 编辑**：设置城市、温度和天气；同步更新桌面。
- **角色 / 通讯录**：保留姓名、头像、背景关系和联系人自动回复编辑。

锁屏密码仅用于模拟剧情，不是安全保险箱。请勿复用真实手机密码；JSON 备份会包含模拟密码。忘记密码可通过已有备份恢复，或清除此站点的浏览器数据（会同时丢失本地内容）。

## 应用

- **小红书**：瀑布流笔记、查看、发布、编辑、删除、配图、搜索、点赞。
- **微信**：参考手机深色布局的会话列表，底部“微信 / 联系人 / 发现 / 我”四个入口。保留现有单聊和联系人；“发现 / 我”为简化展示页。没有导入参考截图中的私人联系人、群组或设备信息。
- **编辑微信单聊记录**：打开聊天，点右上角“编辑”进入记录列表，或直接点消息气泡编辑该条；联系人编辑页也有“编辑聊天记录”。可修改我／对方、正文和发送时间，添加过去的消息，或删除指定消息。保存后按时间显示，不触发自动回复或关键词剧情；旧记录会补齐内部消息标识以便准确编辑，备份仍保留聊天内容。
- **微信群组**：微信右上角 ＋ → 新建群组，设置群名、上传头像并勾选已有联系人。当前角色自动加入；不上传头像时使用成员头像拼图。管理群组可修改名称、头像和成员，或删除群组。
- **群消息编排**：在编辑群组中点“编辑群消息”，可指定发送者、正文和时间，修改或删除已有消息，也可进入群聊发送消息，或直接点群消息气泡编辑。开启本地自动回复时，由当前群成员按各自预设候选语句回复。群消息和单聊分别保存，群组、成员、头像及消息均随完整 JSON 备份保存恢复。自动回复是本地规则，不是生成式 AI。
- **微博**：参考真实手机布局的动态流，底部固定“微博 / 视频 / 发现 / 消息 / 我”五个入口。动态支持作者头像、话题、正文、配图、发布时间、来源、点赞数和转发数编辑，评论和转发会保存在本地。
- **微博热搜**：在“发现”查看热搜，点“编辑热搜”新增、修改或删除标题、显示热度、标签与话题详情；上下移动调整排名。点击热搜进入话题页，可发布关联话题的微博。热搜为故事数据，不是实时网络热搜，随 JSON 备份保存恢复。
- **微博视频 / 消息 / 我**：添加有效的 HTTPS 视频直链后可在视频页播放；消息页记录本地互动并支持全部已读；“我”查看当前角色发布的微博、点赞统计和修改顶部关注分组名称。视频播放需网络与链接允许访问，不上传大视频到浏览器存储。
- **电话**：拨号键盘、模拟通话计时、通话记录。不拨打真实电话。
- **Safari**：收藏中的“百度”打开本地搜索历史页面，默认记录“和男生吵架怎么哄”“小狗教育大全”，不会跳转真实百度。支持新增、编辑、删除与清空记录，浏览器本地保存，随完整备份导出恢复。地址栏输入“百度”或百度网址也会进入本地页面。另可添加、编辑和搜索故事内的纯文本网页；其他真实 HTTP(S) 网址通过新标签页打开。
- **备忘录**：黑色背景、大标题、按日期分组的圆角列表，显示标题、摘要与照片缩略图，底部搜索和新建。没有导入参考截图中的私人内容。可新增、编辑、删除、置顶、上传或移除照片，也可手动设置列表显示日期；停止输入约 0.65 秒后自动保存，返回列表或主屏幕前会先保存。
- **备忘录兼容与备份**：旧版单条文字自动保留为一条备忘录；剧情追加的文字继续写入这条兼容备忘录。删除后不会再次凭空恢复。多条备忘录、日期、照片和置顶状态随完整 JSON 备份保存恢复。
- **相册**：本地上传、压缩、查看、删除、照片小组件。
- **相机**：点快门调用手机系统拍照入口，也可从相册选择照片保存；电脑通常打开文件选择器。页面展示最近保存的照片，不是实时摄像头预览。
- 另保留角色、通讯录与设置。**Spotify** 在手机内打开「喜欢的歌曲」歌单，包含指定的 8 首歌，支持搜索、排序、分类、选歌和底部迷你播放器。「热恋夏季」和「樱花草」已接入用户上传的 MP3，点击歌曲行即可播放，单文件和游玩版下载包也内嵌该音频。其他歌曲可在编辑版点击右侧「•••」添加 HTTPS 音频直链；未添加音源时不会模拟播放。游玩版可播放已有音源。旧歌单保留在完整备份的 `spotifyPreviousTracks` 字段中。

天气是可编辑的模拟数据，不是实时预报。社交应用不连接真实平台账号。

## 编排故事线

打开“故事线”，添加节点，或载入三步示例：

1. 打开微信 → 收到朋友的消息。
2. 打开 Safari → 备忘录增加线索。
3. 给指定联系人发送包含“我记得”的消息 → 收到下一条剧情消息。

节点按列表顺序执行，只有第一个未完成的节点会监听触发条件。触发方式支持打开应用、打开指定联系人的聊天、发送关键词、手动推进；效果支持收到微信、联系人来电、追加备忘录、发布小红书或微博。可编辑、删除和调整节点顺序。

编辑完成后开启“剧情运行”。重置剧情进度会允许节点重新触发，但保留此前产生的手机内容。当前版本为顺序故事线编辑，尚不包含分支图和多结局条件系统。

## 保存和备份

默认通过 IndexedDB 保存当前浏览器中的内容，避免壁纸、头像、照片占满较小的 localStorage 配额后连聊天文字也无法保存。启动时优先读取扩展存储，并自动迁移旧版 `phone-life-ios18-v1` 数据；旧 localStorage 副本不会主动删除。仍沿用原 JSON 备份格式，可导入旧版备份。

保存会排队并等待数据库事务完成；失败时页面提示重试或导出备份，当前修改仍保留在页面中，旧的已保存快照不会被失败事务覆盖。存在未保存数据时会尽可能在关闭页面前提醒。若浏览器不支持 IndexedDB，会使用兼容存储模式并提示；若此前的数据无法读取，则先阻止编辑，避免以默认数据覆盖旧记录。浏览器本机空间仍有总容量限制，请定期备份。

更新前请先导出旧版备份，勿清理浏览器数据。新旧版本的保存方式不同，建议后续持续使用新版。换文件路径或域名后未看到原内容时，可导入备份恢复。若部署源码，务必同时上传新增的 `storage.js`；也可将单文件 `Phone-Life.html` 重命名为 `index.html` 单独部署，避免漏传脚本。

设置 → 导出完整备份 / 导入备份，包含联系人、聊天、照片、双壁纸、模拟密码、动态、网页、天气和剧情进度。导入会替换当前内容，建议先导出。图片会压缩保存，但仍受浏览器空间限制；请定期备份。

不同浏览器、文件路径和部署域名可能有独立的存储空间，不会自动同步。不要仅依赖无痕窗口保存内容。

本项目为独立界面设计，不隶属于 Apple 或各社交平台。

## 聊天来电剧情

在故事线中选择“打开指定聊天”，选择对应联系人；效果选择“收到联系人来电”。开启剧情运行后，只有点开指定单聊才触发来电，微信首页、其他会话和聊天记录编辑均不会触发。

来电界面使用联系人现有头像和姓名，支持接听、计时、拒绝和挂断；结束后回到聊天。通话是本地剧情模拟，不拨打真实电话、不访问麦克风。普通来电节点显示后计入已完成。配置重拨流程时，会按该流程重拨，接听并结束后停止；刷新页面可继续未结束的流程，重置剧情进度可重播。通话记录可在电话应用查看。

个人剧情预览可使用 `python3 scripts/build-preview.py --scenario /path/to/private-scenario.json --output /workspace/exports/private-preview.html` 构建。它仅内嵌少量对话增量；首次打开选择原 JSON 备份后在浏览器本地合并，保留原照片与资料，不覆盖已应用剧情之后的后续编辑。私人输出必须保存在仓库外，默认构建不包含完整个人备份。当前 `index.html` 已接入你要求的新增对话与来电规则；已有对应本机数据时自动合并，新浏览器先导入原始备份。

需要提供外部下载时，可显式添加 `--share-scenario`：仅发布指定联系人名字、本次新增的对话与触发规则，不包含原始备份、角色身份信息、其他联系人列表、照片、壁纸或密码。构建前请确认这些新增内容可以公开。此模式输出可放进仓库；私人模式仍禁止写入公开仓库目录。
