# Phone Life · 我的故事手机

基于原有 Phone Life HTML 扩展的 iOS 灵感交互式手机模拟器。所有功能在本地运行，不需要 API 密钥或后端。

## 打开

解压后双击 `index.html`。请将 `index.html`、`ios.css` 和 `ios.js` 保持在同一目录。也可将这三个文件部署到 GitHub Pages / Cloudflare Pages。

本地开发可运行：

```sh
cd /workspace/phone
python3 -m http.server 4173 --bind 0.0.0.0
```

如果浏览器策略禁止直接打开本地文件，请使用上述静态服务器或部署到静态托管。

不需要安装依赖。手机浏览器自动切换到全屏布局；电脑上显示手机边框和快捷编辑入口。

## 自定义手机

- **设置 → 壁纸与锁屏密码**：分别上传锁屏和主屏幕壁纸；支持重置其中一张而不影响另一张。
- **设置密码**：输入两次相同的 4 位或 6 位数字。更改和关闭密码需填写当前密码。
- **锁屏**：设置 → 立即锁定；点“向上轻扫以解锁”或实际向上滑动。设置密码后显示数字键盘，电脑也能使用数字键和退格键。连续输错五次会等待 30 秒。
- **照片**：上传相片后，在照片页面底部选择桌面小组件使用的图片。未指定时显示相册第一张照片。
- **天气小组件 → 编辑**：设置城市、温度和天气；同步更新桌面。
- **角色 / 通讯录**：保留姓名、头像、背景关系和联系人自动回复编辑。

锁屏密码仅用于模拟剧情，不是安全保险箱。请勿复用真实手机密码；JSON 备份会包含模拟密码。忘记密码可通过已有备份恢复，或清除此站点的浏览器数据（会同时丢失本地内容）。

## 应用

- **小红书**：瀑布流笔记、查看、发布、编辑、删除、配图、搜索、点赞。
- **微信**：联系人、聊天记录、预设自动回复。自动回复是本地规则，不是生成式 AI。
- **微博**：可编辑的时间线、发布、配图、删除、搜索、点赞。
- **电话**：拨号键盘、模拟通话计时、通话记录。不拨打真实电话。
- **Safari**：添加、编辑和搜索故事内的纯文本网页；真实 HTTP(S) 网址通过新标签页打开。
- **备忘录**：编辑并保存文本，剧情也能追加内容。
- **照片**：本地上传、压缩、查看、删除、照片小组件。
- 另保留角色、通讯录、音乐与设置。音乐需自行添加可播放的 HTTPS 音频链接。

天气是可编辑的模拟数据，不是实时预报。社交应用不连接真实平台账号。

## 编排故事线

打开“故事线”，添加节点，或载入三步示例：

1. 打开微信 → 收到朋友的消息。
2. 打开 Safari → 备忘录增加线索。
3. 给指定联系人发送包含“我记得”的消息 → 收到下一条剧情消息。

节点按列表顺序执行，只有第一个未完成的节点会监听触发条件。触发方式支持打开应用、发送关键词、手动推进；效果支持收到微信、追加备忘录、发布小红书或微博。可编辑、删除和调整节点顺序。

编辑完成后开启“剧情运行”。重置剧情进度会允许节点重新触发，但保留此前产生的手机内容。当前版本为顺序故事线编辑，尚不包含分支图和多结局条件系统。

## 保存和备份

通过 `localStorage` 保存当前浏览器中的内容，沿用旧版 `phone-life-ios18-v1` 存储键和 JSON 备份格式，可导入旧版数据；新增字段会自动补齐。

设置 → 导出完整备份 / 导入备份，包含联系人、聊天、照片、双壁纸、模拟密码、动态、网页、天气和剧情进度。导入会替换当前内容，建议先导出。图片会压缩保存，但仍受浏览器空间限制；请定期备份。

不同浏览器、文件路径和部署域名可能有独立的存储空间，不会自动同步。不要仅依赖无痕窗口保存内容。

本项目为独立界面设计，不隶属于 Apple 或各社交平台。
